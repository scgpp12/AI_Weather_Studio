## 结论先说

1. **日本版**：直接用気象庁 bosai JSON 里的「府県天気予報・週間天気予報」数字，**原样转述**，写明「気象庁発表・発表時刻」，**不需要予報業務許可**。但**不能**拿 Open-Meteo 等模型数据当成东京明天的预报播出，按気象庁的解释那算「独自予報」，从国外发也要许可。
2. **中国版**：法规要求「只能传播气象台发布的预报，注明气象台名称和发布时间，不得改动内容和结论」。合规的数据源只有气象台（中央气象台／各地气象台）发布的预报；中国官方没有面向个人、境外、商用的公开预报 API。第三方（和风、心知）和 Open-Meteo 的数字**能不能算「气象台提供的预报」没有确认**。2025 年起的《人工智能气象应用服务办法》还明确禁止 AI 服务传播非气象台的预报。中国版是本项目法律风险最大的一块。
3. **地图**：日本用国土地理院瓦片／国土数值情报 N03，写出处即可，YouTube 也不用申请。**中国版建议 MVP 不画中国地图（用城市卡片）**；要画，只能原样用自然资源部「标准地图」并标审图号，任何裁切、加图层都要送审。Natural Earth、GADM、阿里 DataV 都不能直接拿来在面向中国公开的内容里画中国国界。

### 1-3 気象業務法（最关键）

| 结论 | 标记 | 出处 |
|---|---|---|
| 第17条1項：气象厅以外的人做「予報業務」要气象厅长官许可。 | 已验证（官方原文） | https://www.jma.go.jp/jma/kishou/info/ml-17.html |
| 「予報」＝「観測の成果に基づく現象の予想の発表」，即指定时间和地点、基于观测用科学方法预想将来的自然现象，并提供给他人。「業務」＝反复持续地做。**不论发表手段、营利与否**都在许可对象内。 | 已验证（官方原文，申请手引 令和8年9月版） | https://www.jma.go.jp/jma/kishou/minkan/tebiki/kishou_tebiki.pdf |
| **不需要许可的情况**：「気象庁発表の警報や予報、予報業務の許可を受けた事業者の予報を解説したり、そのまま伝達したりする行為も、予報業務許可は不要です。」 | 已验证（官方原文，2026 年手引） | 同上；FAQ：https://www.jma.go.jp/jma/kishou/minkan/q_a_m.html （FAQ 约 6 年前刊登，旧） |
| **需要许可的情况**：自己根据观测资料预想明天天气并在电视、网站发表；把数值预报 GPV 做空间内插、高度修正，**或作为特定地点的预报显示**等改变信息含义的加工。 | 已验证（官方原文） | https://www.jma.go.jp/jma/kishou/minkan/q_a_m.html |
| GPV 原样提供/显示可以不要许可，但建议注明「是数值预报模型的结果」「可能有较大误差」。 | 已验证（官方原文） | 同上 |
| 面向日本国内用户发日本的预报，**不论发布者在国内还是国外**都要许可（外国法人需定国内代表）。 | 已验证（官方原文） | 申请手引 第3节(8)；FAQ |
| 第23条：气象厅以外的人不得发表气象、地象、津波、高潮、波浪、洪水的**警报**。 | 已验证（官方原文） | https://laws.e-gov.go.jp/api/1/lawdata/327AC0000000165 |
| 罚则：第46条，无许可做予报业务（第2号）、违反第23条发警报（第6号），各处 50 万日元以下罚金。 | 已验证（官方原文，e-Gov 法令文本） | 同上 |
| 解说时注意：不要让人误以为是解说者自己的预报；对特定计算结果评论「可能性高/低」会被看成独自预报。 | 已验证（官方原文） | https://www.jma.go.jp/jma/kishou/minkan/q_a_m.html |

**对本项目的含义**：

- 日本版视频把气象厅的天气、气温、降水概率**原样**放上去 + 讲解 = 「そのまま伝達・解説」，不需要许可。**已验证（官方原文）**
- 下面这些会越界，**存在风险**：
  - 用 Open-Meteo / OpenWeatherMap 等模型数据播「东京明天最高 18℃」（＝GPV 当作特定地点预报显示）。
  - 把府県予報的「区域」数值插值成「某区某时」的数字，或用 AI 自己算「体感」「傘指数」之类的预想值。
  - LLM 生成旁白时自己加判断（如气象厅降水概率 30% 时说「明天不会下雨」）。旁白应以天気概況原文和数值为准，只做换说法，不改结论。
- 视频内出处建议写法（依据 PDL1.0 和利用规约例句）：
  「出典：気象庁ホームページ（https://www.jma.go.jp/bosai/forecast/）／気象庁 2026年11月17日05時発表の府県天気予報を加工して作成」。**已验证（格式依据官方原文）**，具体措辞是本调查的建议。
- 警报只能转述气象厅发表的，不能自己说「将发布警报」之类。**已验证（官方原文）**

## 需要用户确认

1. **是否商用（YouTube 开广告收益）**：影响 Open-Meteo（免费版仅非商用）、心知天气、data.cma.cn（禁止经营性活动）等的选择。气象厅数据和国土地理院按 PDL1.0 可以商用。
2. **中国版发在哪里**：只发 YouTube（境外），还是也发 B 站、抖音、视频号等境内平台。境内平台明确适用中国的气象和地图法规，并且 AI 内容要加标识，可能涉及备案。
3. **中国版的数据源**：官方没有面向境外个人、可商用的预报 API。可选：
   - a. 用和风天气等国内持证服务商，先读它的开发者许可协议，确认它能提供「气象台名称＋发布时间」并允许视频使用；
   - b. 中国版先不做，或只做非公开的内部测试；
   - c. 只发境外平台、接受法规适用不明的风险（不建议在没有确认前做）。
4. **视频的观众**：日本版是否也给中国观众看（关系到日本地图的领土表示）；中国版是否会出现台湾、香港城市（关系到地图和用语规范）。
5. **旁白生成规则**：同意「LLM 只能改说法、不得改结论、不加自己的预测」这条硬规矩，并在出片前自动比对数字。
