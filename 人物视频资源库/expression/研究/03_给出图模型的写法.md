# 03 给出图模型的写法（表情研究频道，2026-11-17）

把 01 的表情翻成 Qwen Image 2.1 / GPT 出图 / H3 视频能直接用的中文提示词。**示范句都没跑过**，是写法样板；要用先按速查表的固定做法跑一组小样。

## 三条硬规矩（来自我们自己的错题本和记忆）

1. **只写看得见的状态**：写“脸颊鼓起、下眼睑微微隆起、眼角出现细纹”，不写“开心、甜美、害羞、可爱”这些情绪词。写空词模型会默认画“牙膏广告笑”（错题本第 59 条：只写 calm 就画成在笑）。
2. **不写否定句**：写“不要露下牙”反而会露。改成正面描述：“露出上排几颗牙”。
3. **H3 视频不写说话类词**：说话、台词、念、嘴巴动、字幕、drama 都不写（错题本第 7、37、63 条）；要张嘴就写成表情，例如“嘴唇微微分开”。

另外：
- **强度要写小**。H3 倾向把笑放大（速查表 523 行：要“刚有一点喜色”演成咧嘴大笑）。写“嘴角轻轻上扬一点”，并给参照物“只露出上排两三颗牙”。
- **视频写过程**：每镜写“从什么姿势到什么姿势”（记忆：每镜写肢体动作），加时间顺序“先……再……最后……”。真笑节奏≈1 秒起、2 秒停、1 秒收。
- **要保住的东西放参考图**：手的位置、景别、机位跟参考图走；提示词管表情细节。手的姿势如果很重要（比心、托腮），参考图里就要有（记忆：要保住的东西放进参考图）。
- **不对称要写出来**：“左边嘴角比右边略高一点”“头向左歪”，避免镜像脸。
- 天气主播七七的日常底色是“亲切 + 甜美”，可爱和俏皮留给结尾或花絮。

## 通用句子零件（拼着用）

| 部位 | 可直接用的中文短句 |
|---|---|
| 眼（真笑） | 脸颊向上鼓起，下眼睑微微隆起，眼角挤出细小的笑纹，眼睛弯成浅浅的月牙，瞳孔里有高光 |
| 眼（睁圆） | 眼睛睁得圆圆的，上眼皮抬高，露出瞳孔上方一点眼白 |
| 眉（软） | 眉毛舒展，眉头内侧微微抬起 |
| 眉（惊） | 整条眉毛高高扬起，额头出现几道浅横纹 |
| 嘴（甜笑） | 嘴角向上弯起，嘴唇轻轻分开，露出上排几颗牙 |
| 嘴（抿笑） | 嘴唇抿在一起，嘴角向上翘，右侧脸颊出现一个浅酒窝 |
| 嘴（嘟） | 嘴唇向前嘟起，两边脸颊微微鼓起 |
| 舌尖 | 嘴唇分开一条缝，舌尖从中间露出一点点 |
| 头 | 头向左歪约十度，下巴微微收起 |
| 视线 | 抬眼直视镜头 / 视线落向右下方 |
| 皮肤 | 两颊透出淡淡的粉色 |
| 泪 | 下眼睑积着一层亮亮的泪光，一道泪痕从右眼外眼角滑到脸颊 |

## 逐个表情示范（图 = Qwen 2.1 / GPT；视频 = H3）

### 1. 甜美微笑（开场、结尾）
- 图：七七头向左歪约十度，下巴微收，脸颊向上鼓起，下眼睑微微隆起，眼角挤出细小笑纹，嘴角向上弯起，左边略高一点，嘴唇轻轻分开露出上排几颗牙，双手在胸前轻轻交握，肩膀放松。
- 视频：七七先平静地看着镜头，一秒内嘴角慢慢向上弯起，脸颊跟着鼓起，眼睛弯成浅月牙，同时头向左轻轻歪过去，双手在胸前轻轻交握；笑容保持两秒，再慢慢收回到嘴角微翘。

### 2. 亲切播报（读天气时的底色）
- 图：七七上身微微前倾，嘴角保持轻轻上扬，眼睛看着镜头，脸颊微微鼓起，右手掌心向上朝身旁的天气图展开。
- 视频：七七看着镜头，嘴角一直带着浅浅的弧度，右手从腹前抬起、掌心向上指向身旁的天气图，指完后轻轻点一下头，手收回腹前。

### 3. 开怀大笑
- 图：七七眼睛笑成两道弯月，眼角笑纹明显，嘴张开露出上排牙，头微微后仰，右手手背轻挡在嘴前，左手按在胸口。
- 视频：七七先轻笑，随后头微微向后仰，眼睛笑成弯月，肩膀轻轻抖动两下，右手抬起用手背挡在嘴前，接着上身前倾回到镜头前，笑意留在眼角慢慢收。

### 4. 抿嘴含羞笑
- 图：七七低头约十五度并侧过脸，眉头内侧微微抬起，眼睛从下方抬起偷看镜头，嘴唇抿在一起、嘴角向上翘，右侧脸颊一个浅酒窝，右手手指把耳边一缕头发别到耳后，两颊透出淡粉色。
- 视频：七七视线先落向右下方，嘴唇抿着、嘴角慢慢翘起，头稍低侧过去，右手抬起把耳边头发别到耳后，然后抬眼看一下镜头，又很快把视线移开，肩膀微微缩起。

### 5. 嘟嘴 / 鼓腮
- 图：七七头向右歪约十五度，眼睛睁圆、向上看着镜头，眉头内侧抬起，嘴唇向前嘟起，两颊鼓起，双手握成小拳头放在下巴两侧。
- 视频：七七两颊慢慢鼓起，嘴唇向前嘟起，头向右歪，右手食指轻轻戳一下鼓起的右脸颊，脸颊瘪下去，接着露出笑容。

### 6. Wink
- 图：七七头向右歪，右眼闭上，右侧脸颊上提、右边嘴角明显翘起，左眼也跟着微微眯起，左眉略扬，右手比 V 放在右眼旁。
- 视频：七七看着镜头，右手比 V 举到右眼旁，右眼快速闭上又睁开，右侧嘴角跟着翘起，头向右轻歪一下再回正。

### 7. 吐舌尖（小失误）
- 图：七七眉头内侧微抬，眼睛微眯，嘴唇分开一条缝、舌尖从中间露出一点点，头向左歪，肩膀缩起，右手握拳轻轻贴在头侧。
- 视频：七七先眨一下眼，肩膀缩起，舌尖从嘴唇中间露出一点点，右手握拳轻轻碰一下自己头侧，随后舌尖收回，嘴角弯起笑开。

### 8. 比心
- 图：七七双眼弯成月牙，嘴角上扬露出上排几颗牙，头向右歪，右手拇指和食指交叉成小爱心，举在右脸颊旁，指尖朝上。
- 视频：七七右手抬到右脸颊旁，拇指和食指交叉成小爱心，同时头向右歪、眼睛弯起笑，手停在脸旁一秒后放下。
- 提醒：手指形状模型常画坏；比心要以参考图钉住手型，交付前单独数手指。

### 9. 托腮
- 图：七七上身前倾，双肘撑在桌面，双手掌根托住下巴，手指贴着两颊，脸颊肉被手轻轻推起，眼睛弯起看着镜头，头微微向右歪。
- 视频：七七上身慢慢前倾，双手掌根托住下巴，手指贴着脸颊，头顺着右手歪过去，眼睛弯起看向镜头，停住两秒。

### 10. 惊讶捂嘴
- 图：七七整条眉毛高高扬起，额头出现浅横纹，眼睛睁得圆圆的露出上方眼白，双手手掌并拢挡在嘴前，指尖朝上，肩膀耸起，头微微后收。
- 视频：七七眉毛一下扬起、眼睛睁圆，嘴唇张成小圆形，紧接着双手抬起挡在嘴前，肩膀耸了一下；一秒后双手放下，眼睛弯起，嘴角上扬笑开。
- 顺序很重要：先睁眼张嘴，再上手，最后转笑。

### 11. 感动落泪
- 图：七七眉头内侧抬起向中间挤，眼眶泛红，下眼睑积着亮亮的泪光，一道泪痕从右眼外眼角滑到脸颊，鼻头微红，嘴唇抿着、嘴角同时微微上扬，右手指尖轻抹右眼下方。
- 视频：七七眉头慢慢向中间挤起，眼眶泛红，泪光在下眼睑聚起，一滴泪从右眼滑下脸颊，她低下头，右手指尖抹去泪痕，再抬头，嘴角带着一点笑，肩膀随着吸气起伏一下。

### 12. 委屈（坏天气、下雨）
- 图：七七眉头内侧抬起成八字，眼睛微微下垂看向镜头，嘴角向下压，下巴微微皱起，双手握拳放在胸前。
- 视频：七七看着身旁的雨天图标，眉头内侧慢慢抬起，嘴角向下压，下巴皱起，双手握拳收到胸前；随后吸一口气，眉毛舒展，嘴角重新向上翘，对着镜头点一下头。

## 不同模型的差异（写法上的）

| | Qwen Image 2.1（编辑/参考图） | GPT 出图 | H3 视频 |
|---|---|---|---|
| 喂法 | 照速查表的原配方（参考图张数、种子规则不改） | 一段完整中文描述即可 | 照速查表原脚本；文字编码器 8 位版 |
| 表情强度 | 中等可控 | 容易“偏满”，需写小 | **容易放大**，写最小强度 + 参照物 |
| 手 | 参考图里有就保得住 | 比心、托腮易画坏手指 | 手的动作写成先后顺序 |
| 已知坑 | Edit 改小特征会重画整张脸（记忆）→ 表情小修改用局部重绘或像素 | — | 不写说话类词；台词短的镜头会被念出来（错题本 63 条） |
